WorldGuessr vs OpenGuessr

OpenGuessr is a free Street View game by a solo developer in Austria, since 2024. WorldGuessr is a free Street View game by a solo developer, since 2024. They are the two closest free alternatives to GeoGuessr.

Short answer

Both are free, unlimited, no account needed, with ranked duels and free map making. On the basics they match.

WorldGuessr has the better maps, the more active community with a real forum, a true No Move mode with no road names on screen, native apps, five languages and public code.

OpenGuessr has more niche modes: image guessing, meta guessing, tournaments and color filters.

Where WorldGuessr is better

  • Better maps: 71,187 community maps, each with its own page, reviewed before they go live. 93 country maps with recognition guides.
  • A more active community, and a forum. Guides, meta threads and map feedback live on the WorldGuessr forum, next to Discord and YouTube. Updates ship every week. OpenGuessr has a Discord and no forum.
  • A true No Move mode. WorldGuessr draws Street View itself, so No Move has no road names and no Google controls. OpenGuessr's NMPZ runs on the Google embed and keeps the road names. Among free alternatives, only WorldGuessr does this.
  • Parties up to 200 players, with chat, emotes and team duels inside the party.
  • Native Android and iOS apps. OpenGuessr has none.
  • Five languages. OpenGuessr is English only.
  • Public source code. OpenGuessr's game code is private.

Where OpenGuessr is better

  • More modes: Image Guessr, Meta Guessr, tournaments, and grayscale, inverted, hue shift and blink filters.
  • An education site with country guides and quizzes.
  • A bigger Discord (30,000+ members).

Source code: the only one you can inspect

WorldGuessr's code is public at github.com/codergautam/worldguessr (PolyForm Noncommercial). Anyone can read how rounds are picked, how scoring works and how ranked ratings move, and run their own copy for noncommercial use. Source-available, and free for anyone to inspect.

OpenGuessr calls itself 'partially open-source'. Its own words: 'While the complete website isn't, parts of OpenGuessr are open-source.' Some libraries and its education site are open. The game has no public repository. Calling OpenGuessr 'open source' is not what its site says.

Verdict

Same core loop. WorldGuessr wins on maps, community, No Move, apps, languages and code. OpenGuessr wins on mode variety and Discord size.

For most players, WorldGuessr is the more complete free game. Pick OpenGuessr for the filters, image guessing and tournaments.

Questions

Which has the better community?

WorldGuessr. It has a forum for guides, meta and map feedback, plus Discord and YouTube, and weekly updates. OpenGuessr has a bigger Discord and no forum.

Does OpenGuessr have a No Move mode?

No. It has NMPZ on the standard Google embed, which still shows road names. WorldGuessr's No Move uses its own renderer: no road names, no Google controls.

Is OpenGuessr open source?

Nope, by its own words. Some libraries and its education site are open. The game is not. WorldGuessr's full game code is public.

Does OpenGuessr have an app?

No. WorldGuessr has native Android and iOS apps.
